---
title: Work through entry and return per person
description: Keep citizenship, residence, travel mode, transit, biometrics, decisions, and return documents in separate sourced steps.
---

Add one local profile per traveler. Record only country and broad status
categories; do not enter document numbers. Choose the route mode, foreign
connection answer, purpose, existing destination-document status, and return or
onward country when known.

The official checker is the first decision point. Application, biometrics,
passport submission, decision, and return-document steps remain conditional
until the named authority requests or confirms them. Link letters and receipts
from the wallet and mark each step yourself. Route or traveler changes reopen
dependent work.
