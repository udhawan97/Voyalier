---
title: The concierge cockpit
description: Set up the people and preferences once, follow sourced next actions, and move between Voyalier and live travel providers without losing the evidence trail.
---

The concierge cockpit is the first section inside a trip. It turns the route,
party, confirmed records, imported documents, and traveler choices into one
ordered workbench. The percentage reflects only tasks that **you** marked done
or not applicable. It is not a readiness, visa, safety, or booking score.

## Start with the trip setup

Record the island or neighborhood if you know it, group size, adult and child
counts, bedrooms, pace, driving preference, planning currency, and an optional
budget range. Voyalier keeps these details locally and reuses them in provider
briefs. A blank answer remains visibly undecided.

Add one profile for each traveler using a readable local label, two-letter
passport and residence countries, and a broad residence-status category. Do
not enter passport numbers, visa numbers, document numbers, or credentials.
When the route or traveler context changes, review the official entry route
again.

## Work the next actions

The list promotes unresolved decisions and missing evidence. Change a task to
**In progress**, **Waiting**, **You marked done**, **Not applicable**, or
**Needs recheck**. Voyalier does not silently turn a provider response or a
government requirement into a completed task.

For Chicago to Hawaiʻi, the cockpit asks whether every segment stays inside the
United States before it shows domestic identification guidance, and keeps the
Hawaiʻi arrival declaration separate. A foreign connection reopens
international transit and return review. For Chicago to Montréal, it gives
every traveler a Canada-entry authority route and a distinct return or onward
step. The official portal decides the actual case.

## Compare and book

Provider cards open documented search or destination links for flights, stays,
restaurants, community research, and trails. Each card says which details the
link can carry and which details must still be entered on the provider. Copy
the concise brief when a provider cannot accept all trip fields in its URL.

Ratings, prices, availability, cancellation terms, account data, and the final
transaction remain on the provider. After booking, return to Voyalier and
[import the confirmation](/Voyalier/guides/importing-confirmations/) so the
itinerary comes from reviewed evidence.

## Build the document wallet

The wallet can index confirmations already imported into this trip and hold
encrypted PDF, JPEG, or PNG originals. Each file may be up to 20 MiB, with 100
files per trip and 500 MiB of raw attachments across the workspace. That
workspace cap leaves room for encrypted storage expansion inside a portable
backup. Voyalier checks the file signature before storing it and shows the
trip's local use. Give an item a plain label, category, optional traveler links,
and an optional review or expiry date. A wallet item may point only to a source
from the same trip. Removing the wallet link does not remove its source;
removing the original file is a separate confirmed action.

**Save a copy** decrypts one file on your explicit click and gives it to the
browser's download flow. A preview request is discarded if you close, replace,
or leave it before decryption finishes. Voyalier does not embed PDF active
content, run OCR, or claim that an exported identity file is redacted. Encrypted
workspace backups include these originals, so wallet size also affects backup
time and size.

## Track money without hidden conversion

Add estimates, committed charges, and refunds in the currency shown by the
source. The cockpit totals each currency separately. It does not infer exchange
rates, fees, taxes, or a universal total.

## Before travel day

Import final confirmations, save official portal results as appropriate,
download available city packs, and check the Today view. Use the cockpit again
whenever the route, dates, people, or document circumstances change.
