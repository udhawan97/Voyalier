# Plan: v0.12.0 release remediation

Base: `19d2c55`. The cleanup candidate includes the selected dev-review fixes,
the contributor-guidance correction, and the current bounded Rust patch group.

## Release blockers

1. **Security lock refresh.** Update the lockfile from vulnerable `rustls`
   0.23.41 to the patched compatible release and move `event-listener` off the
   known-unsound 5.4.1 release. Re-run the repository security workflow locally
   where possible and require the hosted `dependencies-and-secrets` check.
2. **Visible startup failure.** Replace the log-only storage-open failure path
   with a native error dialog that can be shown before the Tauri service is
   available. Keep the message non-destructive and avoid exposing filesystem or
   secret details.
3. **Packaged preview acceptance.** Build the macOS application with updater
   artifacts disabled, launch it against disposable data, import a synthetic
   image or PDF, and verify the in-memory preview on the packaged webview. The
   first installed-app pass proved PNG paint but exposed a blank PDF when a
   `blob:` URL was placed in a sandboxed frame on WKWebView; a follow-up
   `data:` frame stayed blank as well. Preserve the no-persistence boundary by
   rendering the decrypted PDF bytes to a canvas instead of relying on the
   WebView's document plug-in, cover paging/error cleanup behavior, then repeat
   the packaged PDF check with a separately rendered fixture. Use the
   Apache-2.0 `pdfjs-dist` renderer as a lazy, offline-only web dependency: it
   makes no network request, receives only the selected in-memory bytes, and
   remains replaceable behind the wallet preview component. Record its emitted
   bundle cost during verification.
4. **Release records.** Put all not-yet-published fixes in the 0.12.0 changelog
   section, refresh the verification ledger with exact candidate evidence, and
   keep unresolved platform limits explicit.
5. **Dark concierge contrast.** Installed-app review showed the cockpit hero
   inheriting the theme-flipping `--voy-ink` token as its background. In dark
   mode that turned the atlas field pale while its on-accent copy remained
   white. Keep this signature route surface dark in both themes, preserve the
   existing layout and reduced-motion behavior, and verify the correction in
   the packaged app before publication.
6. **Deterministic web gate.** The release-candidate full suite exposed two
   scheduling races in existing assertions: one checked focus before the
   component's focus effect ran, and one allowed only the default one-second
   wait for a deferred notes panel while all suites were contending for the
   machine. Keep the same UI expectations, but wait explicitly for the claimed
   focus and readiness states, then repeat both focused suites and the complete
   gate.
7. **Untrusted PDF resource bounds.** Council review found that closing during
   the lazy renderer import could still start a PDF task afterward, and that a
   PDF-controlled page aspect ratio or embedded image could exceed the intended
   preview budget. Recheck cancellation before decoding, cap PDF.js image and
   canvas allocation, reject non-finite or non-positive viewports, fit rendered
   pages to explicit edge and pixel limits, and cover the lazy-close and hostile
   dimension paths before promotion.

## Implemented locally

- The lockfile selects patched compatible releases of `rustls`,
  `rustls-webpki`, and `event-listener`.
- Desktop startup reports storage-open failures with a native dialog before it
  exits; guided retry and recovery remain outside this release.
- The unpublished fixes are recorded under 0.12.0 with the intended release
  date. Packaged preview and startup-failure acceptance remain release gates.

## Gate

Run focused Rust/desktop tests while iterating, then `make check`, production
dependency audit, credential-pattern scan, `git diff --check`, Graphify update
plus a scoped query, hosted branch checks, the keyless release dry run, Windows
installed-app/updater acceptance, protected tag build, artifact verification,
and the mandatory two-round council review before publication.
