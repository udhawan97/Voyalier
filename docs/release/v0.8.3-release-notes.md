# Voyalier v0.8.3 — The request payload is declared

Voyalier 0.8.3 closes the largest gap the 0.8.2 architecture review found and
deferred. It changes nothing a traveler can see. It is an internal guard, and
it exists so that a specific class of silent breakage stops being possible.

## Changed

- The route manifest now declares each request's payload, and three separate
  guards hold the two transports to it.

  Voyalier speaks to its own local engine two ways — over HTTP in the browser,
  over Tauri commands on the desktop — and both write field names by hand on
  one side and read them by name on the other. 72 of the 81 operations do this.
  Until now nothing compared the two halves: renaming one field in the desktop
  bridge left the trip editor dead while the whole test suite stayed green.

  The manifest now carries those key names, and they are checked from the web
  side (what each transport actually puts on the wire), from the local server,
  and from the desktop app. Any two agreeing while the third disagrees fails
  the build.

- Writing the guard surfaced a case the review had missed: five operations
  forward a whole object to a struct the desktop app re-declares locally rather
  than sharing. Both facts are now recorded and both are checked.

## Documentation

- The architecture overview's decision index listed four records and there are
  twelve; it now lists all of them.
- The agent guide's description of the route manifest and of what the
  integration tests cover was written before payloads were declared, and said
  less than the guards now enforce.
- v0.8.2 shipped without release notes of its own. They are written and filed
  alongside the rest.

## Trust boundaries kept intact

- No traveler-visible behavior, contract shape, route, migration, provider,
  telemetry, or hosted-service behavior changed.
- The manifest stays hand-maintained and is never regenerated from a gateway;
  generating it would make the assertion check itself.

## Known limitations

When a payload row says the whole object is forwarded, the guard proves the
forward happened, not that the TypeScript interface and the Rust struct agree
field by field. That is a second gap, 18 request bodies and 16 desktop commands
wide, and it needs its own decision record. It is stated in
[ADR-0012](../architecture/ADR-0012-the-route-manifest-declares-its-payloads.md)
so the next review does not rediscover it as if it were new.

Download the Apple Silicon macOS `.dmg` or Windows x64 `.exe`/`.msi` from the

The installers are not yet OS code-signed, so follow the documented
[first-launch steps](https://udhawan97.github.io/Voyalier/download/). Updater
artifacts are independently signed and verified by Voyalier.
