# Voyalier v0.8.1 — Clear feedback, complete navigation

Voyalier 0.8.1 is a focused user-flow repair. It adds no travel authority,
provider, data format, or remote behavior; it makes five existing interactions
tell the truth about what happened and where the traveler should go next.

## Fixed

- Invalid activity times and saved-reading tags now name, mark, and focus the
  field that needs correction. Editing that field clears the message, and an
  invalid request is no longer presented as something Retry can fix.
- A valid two-letter passport code stays valid when a save fails because the
  local engine is unreachable. The workspace recovery banner owns the offline
  failure while the entered code and already loaded guidance remain intact.
- Visa progress distinguishes the traveler checklist from the authority guide:
  for example, **0 of 1 complete across 4 guide steps**.
- A named continuation control reveals trip sections hidden to the right at
  320–375 px, then disappears when there is nothing more to reveal.
- Both compact and Settings theme radios expose the names Light, System, and
  Dark to assistive technology even when the visible captions are hidden.

## Trust boundaries kept intact

- Validation still comes from the existing local engine and stable contract
  details; no duplicate browser authority was introduced.
- Passport nationality remains context for authority-backed preparation, never
  a Voyalier decision about visa eligibility.
- Saved reading remains traveler-curated, untrusted reading material and cannot
  become evidence or change readiness.
- No contract, route, migration, provider, telemetry, or hosted-service behavior
  changed.

## Install

Download the Apple Silicon macOS `.dmg` or Windows x64 `.exe`/`.msi` from the
[GitHub release](https://github.com/udhawan97/Voyalier/releases/tag/v0.8.1).
The installers are not yet OS code-signed, so follow the documented
[first-launch steps](https://udhawan97.github.io/Voyalier/download/). Updater
artifacts are independently signed and verified by Voyalier.

## Verification in this release

The React suite covers field ownership, focus, correction, retry boundaries,
offline nationality saves, guide-step wording, narrow navigation, and accessible
theme names. A real loopback-browser journey additionally exercised the repaired
flows through Axum and SQLite at 320, 375, 768, and 1280 CSS pixels, including
offline recovery, theme persistence, and horizontal-overflow checks. The full
Rust, desktop, integration, security, packaging, updater-artifact, checksum,
provenance, and live-download gates remain release requirements.
