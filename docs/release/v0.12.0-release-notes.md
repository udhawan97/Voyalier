# Voyalier v0.12.0 — Everything between here and there

Voyalier now gives each trip one concierge cockpit for the work between deciding
to go and being ready to leave. Record the group once, follow explicit next
actions, carry a search brief to the right provider, bring the final evidence
back, and keep travel files and cost decisions in the same local workspace.

## Highlights

- A route-led cockpit orders traveler setup, flights, stays, entry review,
  document collection, local transport and money work. Progress reflects only
  states the traveler chooses.
- Google Flights, Airbnb, Expedia, Yelp, Reddit, AllTrails and official
  destination sources open through qualified links. Each card names the fields
  already carried and those that still need entry; live prices, ratings,
  availability and account details remain on the provider.
- Per-person preparation keeps destination entry and return-to-residence steps
  separate. The Hawaiʻi projection uses domestic U.S. identification and state
  arrival sources. The Montréal projection asks Canada's official checker and
  gives each traveler a separate official return-to-U.S. source based on broad
  status.
- The encrypted wallet accepts PDF, JPEG and PNG files, validates their content
  signatures, caps each file at 20 MiB, each trip at 100 files and the workspace
  at 500 MiB of raw attachments, prevents duplicates, links a file to a specific
  preparation requirement, and supports an explicit in-memory preview,
  save-copy and deletion. Pending previews are invalidated when closed,
  replaced or unmounted.
- Split-island trips retain separate bases and create an explicit transfer task,
  including gap and overlap warnings when dates are known.
- Estimates, commitments and refunds are totaled per currency without automatic
  conversion. Missing amounts and unknown taxes remain visible without entering
  a false zero.
- The settings guide and public documentation explain the full loop and credit
  the open-source itinerary, route and offline products used as research.
- This release also carries the journey board, stable calendar lineage,
  amendment review and restore, source-return search, narrowed sharing previews,
  updater-setting boundaries, vault error clarity, and dependency repairs that
  accumulated after v0.11.1.

## Verification

Publication is gated on the complete repository check, live loopback integration
suite, production dependency audit, credential-string scan, refreshed Graphify
query, responsive browser inspection, an isolated signed macOS source-build UI
run, and two independent council rounds. The protected tag workflow must then
build both release platforms, create checksums and provenance attestations, and
leave the GitHub release in draft until the assets and updater metadata are
verified.

The [verification ledger](v0.12.0-verification.md) records the implemented plan
scope, exact local evidence and publication gates without treating browser or
mock-runtime checks as installed-app proof.

## Known limits

- Voyalier does not purchase, submit applications, log in to providers, or claim
  authority over entry, safety, health, prices, availability, ratings or opening
  hours.
- Provider pages may change their URL or ignore a carried field. The cockpit
  keeps an explicit verification state and search brief rather than claiming the
  handoff is complete.
- Binary wallet files have a sandboxed, in-memory PDF/image preview. There is no
  OCR, annotation, redaction pipeline, HEIC/Office support or background cloud
  sync.
- macOS ships for Apple Silicon and is not Apple-notarized. Windows installers
  do not carry a paid Authenticode publisher identity, so operating-system
  warnings may appear.
- Automated accessibility and reflow checks do not replace a manual
  screen-reader listening pass.
  See the [full changelog](https://github.com/udhawan97/Voyalier/blob/main/CHANGELOG.md)
  for detailed behavior and trust boundaries.
