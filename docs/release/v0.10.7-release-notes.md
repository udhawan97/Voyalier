# Voyalier v0.10.7 — The next step carries you back

Voyalier now keeps the return path through the parts of a trip that need attention. Readiness
findings open the local context that can address them, temporary Search and Settings detours unwind
to the trip section that opened them, and review can be narrowed without turning evidence approval
into a bulk action.

## Highlights

- Readiness findings open the matching schedule context, a preselected Stay form, the pending
  review queue, Visa, or Prepare. These are navigation aids, never claims that entry, health,
  safety, availability, price, or booking questions are settled.
- Duplicate-import recovery can open the existing stored document without fetching its sealed
  body or exposing its internal identifier in the URL.
- Review filters combine extraction warnings, fact type, and extraction method while confirm,
  edit-and-confirm, dismiss, and undo remain one suggestion at a time.
- Nested Search and Settings journeys now preserve the private query, trip section, browser
  history order, and restored page focus without putting record targets in durable URLs.
- Passport suggestions stay clear of Save on narrow screens, empty Search explains how to enable
  its action, and browser backup copy accurately describes the local SQLite workspace and the
  desktop-only file bridge.
- The Plan register stays inside a 320-pixel WebKit viewport, Create Trip returns focus to its exact
  opener, and English and Spanish Vault guidance keeps its sentence boundary.
- The public-docs build pins the patched `nanoid` 3.3.18 release; the app runtime and network
  surface are unchanged.

## Verification

The exact tagged commit is required to pass the repository's complete local gate; focused Chromium,
Playwright WebKit, and real Safari reduced-motion acceptance; two independent council rounds;
GitHub CI, docs, security hygiene, and CodeQL; protected macOS and Windows release builds; checksum
manifests; updater signatures; and GitHub artifact attestations before this draft is published.

## Known limits

- macOS ships for Apple Silicon and uses an ad-hoc platform signature; it is not Apple-notarized,
  so Gatekeeper may require the documented manual-open flow.
- Windows installers carry Voyalier updater signatures and are checksummed and attested, but they
  do not have an Authenticode publisher identity and the Windows runtime is not manually exercised
  in this release pass. Windows may therefore show SmartScreen.
- Automated semantic accessibility, keyboard, reflow, contrast, and reduced-motion checks do not
  replace a manual screen-reader listening pass.
- Voyalier remains a local-first evidence workspace. It does not book travel or claim authority
  over visas, safety, health, prices, availability, or opening hours.
