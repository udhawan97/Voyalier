# Voyalier v0.11.0 — The shortlist stays yours

Voyalier now keeps more of the traveler's own decisions visible without turning
them into stronger claims. Saved places lead the map, packing progress counts
only accepted checklist rows, and the share-safe brief can be copied as plain
text as well as printed or saved as PDF.

## Highlights

- Saved and suggested map points have distinct, theme-aware markers, a text
  legend, and an expandable place register. Matching points appear once as
  saved, and saved coordinates remain usable after their source pack is gone.
- Packing progress excludes suggestions until the traveler adds them. Hide
  packed changes only the current view and always offers a path back; it does not
  change trip readiness or rewrite the checklist.
- The brief now renders confirmed rail, coach, ferry, and hire-car legs already
  present in its redacted projection. Copy brief uses a separate safe-field
  allowlist, announces success, and reports unavailable clipboard access without
  hiding the existing print/PDF route.
- Repeated row actions carry the row's name for screen readers and speech input,
  the live trip-creation rules and searchable corpus each have one
  implementation, and a focused Visa accessibility budget protects the existing
  destination journeys without changing product behavior.
- UUID and the JavaScript web/docs toolchain receive compatible patch and minor
  updates. No provider, migration, gateway method, route, Tauri command, sealed
  column, city-pack schema, or source license changes.

## Known limits

- macOS ships for Apple Silicon and uses an ad-hoc platform signature; it is not
  Apple-notarized, so Gatekeeper may require the documented manual-open flow.
- Windows installers carry Voyalier updater signatures and are checksummed and
  attested, but they do not have an Authenticode publisher identity and the
  Windows runtime is not manually exercised in this release pass. Windows may
  therefore show SmartScreen.
- Map points remain open-data suggestions and traveler-kept places, never claims
  about hours, access, availability, price, or safety. Packing completion is not
  travel readiness. A copied brief is a redacted itinerary aid, not a booking or
  live-status confirmation. System clipboard history, device sync, or a
  clipboard manager can retain its redacted text after copying.
- Automated semantic accessibility, keyboard, reflow, contrast, and
  reduced-motion checks do not replace a manual screen-reader listening pass.
- Voyalier still does not book travel or claim authority over visas, safety,
  health, prices, availability, or opening hours.
