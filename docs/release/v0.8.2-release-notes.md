# Voyalier v0.8.2 — One copy of each rule

Voyalier 0.8.2 comes out of an architecture review of the parts of the codebase
that change most often. It adds no travel authority, provider, data format, or
remote behavior. It repairs one behavior the demonstration build had quietly
lost, three panels that hid a failure, and several rules that existed in more
than one place with nothing holding the copies together.

## Fixed

- Chat again raises its "Voyalier isn't the authority" card for every
  high-stakes question. The demonstration build carried its own copy of the
  word list behind that card and the copy had fallen to twenty of the engine's
  forty-eight terms and none of its six multi-word phrases, so questions about
  entry requirements, customs, ESTA, Schengen, overstaying, quarantine,
  malaria, terrorism, curfews, travel insurance, and yellow fever got a local
  model's answer with nothing above it. The list is now one file both sides
  read.
- Opening AI provider settings, reading the encryption status, and setting a
  passphrase now state a failure instead of dropping it. The encryption panel
  had been removing itself from Settings entirely when the local engine could
  not be reached, with no message; the workspace status indicator had gone on
  reading Ready through all three.
- Currency conversion is computed one way rather than two. An unknown currency
  shows nothing rather than a rate of one, which would read as a real quote.

## Changed

- Great-circle distance, the "this source returned something unreadable"
  sentence, and a test helper for opening the sample trip each existed in
  several places and now exist in one.
- Two internal guards were taught to check what they claimed to check: the
  declaration of which database columns are encrypted is now reconciled against
  the database itself, and a second check covers a failure that could only have
  appeared on an existing traveler's machine during an upgrade.

## Trust boundaries kept intact

- Only the demonstration build lost the authority pointer. The shipped desktop
  app and local server always used the full list.
- No contract, route, migration, provider, telemetry, or hosted-service
  behavior changed.
- Voyalier still points at official sources and dated snapshots; it claims no
  legal, medical, safety, pricing, availability, or opening-hours authority.

## Known limitations

The same review recorded four larger findings this release deliberately does
not address, each needing its own decision record: the two transport layers
that are almost entirely forwarding, the database schema stated in three
places, the hand-written row mappings, and the request payloads no guard
covered. The last of these is addressed in 0.8.3. All four are written down in
`docs/superpowers/plans/2026-08-01-architecture-deepening-0.8.2.md`.

## Install

Download the Apple Silicon macOS `.dmg` or Windows x64 `.exe`/`.msi` from the
[GitHub release](https://github.com/udhawan97/Voyalier/releases/tag/v0.8.2).
The installers are not yet OS code-signed, so follow the documented
[first-launch steps](https://udhawan97.github.io/Voyalier/download/). Updater
artifacts are independently signed and verified by Voyalier.
