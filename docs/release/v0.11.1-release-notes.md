# Voyalier v0.11.1 — The day returns to its source

Voyalier's travel-day summaries now keep the route back to the local records
that produced them. Today can open the exact confirmed fact or traveler-authored
plan behind each row, while **If something slips** can open the confirmations
behind handoffs and exposed connections without pretending to monitor live
operations.

## Highlights

- Every Today row and next anchor carries an optional local target. **Show in
  Plan** focuses the exact confirmed fact or traveler-authored plan, with a clear
  Plan-level fallback if the record disappeared. Targets never enter the URL.
- Every handoff, exposed leg, and operator pointer in the disruption view can
  return to its confirmed fact. Slack and dependent counts come only from the
  local plan; Voyalier does not predict delays, fetch status, or claim another
  service exists.
- Cross-language parity now pins Today, city-pack suggestions, field-value
  suggestions, lexical scoring, and redacted briefs. The closure corrected pack
  coverage, Unicode whitespace, undated-item ordering, and cross-family sharing
  omissions in the shipped TypeScript mock.
- The production web gate now scans every emitted asset for markers derived from
  behavioral fixtures. Runtime catalog data remains compact; parity cases and
  sensitive canaries remain test-only.
- The public product story now uses current-source captures from a disposable
  fictional trip, and the desktop notes correctly describe direct Tauri IPC,
  vault/updater behavior, and current platform-signing limits.
- No provider, database migration, sealed column, gateway method, HTTP route,
  Tauri command, city-pack license, or authority boundary changes.

## Verification

Publication is gated on the complete repository check, production dependency
audit, credential-string scan, refreshed Graphify query, current-source WebKit
captures, native Safari acceptance, an exact candidate desktop build, and two
independent council rounds. The protected release workflow must then build both
platforms from the tagged commit, pass installed updater swap and recovery on
real Apple Silicon and Windows, publish signed updater metadata and checksums,
and leave the release in draft until the assets are verified.

## Known limits

- macOS ships for Apple Silicon and uses an ad-hoc platform signature; it is not
  Apple-notarized, so Gatekeeper may require the documented manual-open flow.
- Windows installers carry Voyalier updater signatures, checksums, and artifact
  attestations, but no Authenticode publisher identity, so Windows may show
  SmartScreen.
- Today and disruption are local projections, not monitoring. A slack value is
  arithmetic over entered local times—not a forecast, minimum connection-time
  judgment, availability claim, or promise that the journey will work.
- Automated semantic accessibility, keyboard, reflow, contrast, and
  reduced-motion checks do not replace a manual screen-reader listening pass.
- Voyalier still does not book travel or claim authority over visas, safety,
  health, prices, availability, or opening hours.
